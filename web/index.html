导入与隐私

文件在本机解析；网页读取使用 DeepSeek，会先确认并产生 API 费用。正文预览后点击保存才进入资产，不自动发送模型。PDF需含文字；视频请导入字幕。

浏览器采集

在自己的浏览器完成登录，再采集当前可见网页或选中的 JD 正文。不是自动爬站，不读取密码或 Cookie。

  1. 下载并解压插件。
  2. Chrome / Edge 扩展管理 → 开发者模式 → 加载已解压扩展。
  3. 打开招聘页，按网站要求登录，选中 JD 正文。
  4. 点击插件预览，再带到积木确认保存。
下载浏览器插件

积木需在本机运行。插件原型尚未在真实招聘站完成扫码登录验收；网页无法采集时可手动复制导入。

从 GitHub 导入

公开仓库无需登录。私有仓库需先在本机终端运行 gh auth login，本页不接收令牌。

只读仓库简介与 README，不克隆、不改代码、不提交。读取不消耗 DeepSeek 额度；核对预览后才保存到资产。

GitHub 授权

当前 OpenCode 不支持 GitHub 的自动客户端注册。请使用 GitHub Token，按所需仓库授予最小权限；外部操作仍逐次确认。
