# Agent Workbench

Standalone project. Preserve the original Ali application and visualization.
Python standard-library backend, native HTML/CSS/JS frontend. No global installs.
Use OpenCode as an external process; never emulate successful model execution.
Keep private data, credentials, generated runtime and vendor binaries out of Git.
Model outputs are untrusted proposals, never instructions to execute arbitrary code.
Only a user approval may commit a proposal to a versioned artifact. Verify quotes
against imported source text and reject stale revisions atomically.
Tests use temporary databases and explicitly labelled local model fixtures.
