# 积木主流程演示脚本

时长约 60 秒，只展示「材料 → 技能 → 对话 → 文稿 → 保存」这条主线。

## 开始前

只展示公开的DeepSeek官方入门文档，不展示个人经历、API Key或设置页。使用2026-10-21真实运行的“DeepSeek 官方入门文档：中文接入笔记”任务回放，不把回放说成现场生成。公开展示可用本地 `/?showcase=1`，所有保存操作只能在正常空间中完成。

| 时间 | 鼠标操作 | 讲解 |
| --- | --- | --- |
| 0–8 秒 | 点击侧栏「资产」，打开「官方资料」文件夹 | 这是积木，一个通过对话把零散材料整理成成果的个人工作台。材料先放在资产里。 |
| 8–18 秒 | 点击「新对话」和输入框旁的 `+`；展示资产选择，再展示「整理材料」技能 | 对话可以引用自己的文件和可复用技能。技能规定整理方法，不是再开一个聊天机器人。 |
| 18–28 秒 | 点击最近对话「DeepSeek 官方入门文档：中文接入笔记」 | 这里回放一次真实完成的任务：把官方文档整理成一份接入笔记。 |
| 28–38 秒 | 展开「3 个步骤」，停留在 Agent 和工具记录 | 底层由 OpenCode 执行，依次研究资料、生成文稿和核对来源。处理过程可见，失败也直接显示。 |
| 38–50 秒 | 点击 Markdown 文件卡片，在右侧预览；展开「来源依据」 | 结果是一份可以继续修改的文稿，每条依据都能回到所选原始材料。 |
| 50–60 秒 | 返回资产，打开「学习笔记与画板」中的同一文稿或OpenCode Loop画板 | 需要保留时，由用户加入资产，下次还能再次引用。画板可继续编辑，不只是图片。 |

## 录制原则

- 真实任务耗时可剪掉，标注「处理中已加速」，不替换执行结果。
- 已保存的阅读卡只展示保存状态，不演示不存在的再次保存按钮。
- 不宣称 MCP 全部可用，不演示未验收的自动登录、图片识别或视频转写。
- 不需要额外付费调用来录制上述回放。录制文件完成后再加入 README，当前脚本不是视频。
