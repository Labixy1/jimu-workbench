# 积木主流程演示脚本

时长约 60 秒，只展示「材料 → 技能 → 对话 → 文稿 → 保存」这条主线。

## 开始前

只展示公开的 OpenCode 发布资料，不展示个人经历、API Key 或设置页。准备 `v1.19.3` 官方发布摘要；使用已真实运行完成的阅读卡对话回放，不把回放说成现场生成。

| 时间 | 鼠标操作 | 讲解 |
| --- | --- | --- |
| 0–8 秒 | 点击侧栏「资产」，打开公开发布资料所在文件夹 | 这是积木，一个通过对话把零散材料整理成成果的个人工作台。材料先放在资产里。 |
| 8–18 秒 | 点击「新对话」和输入框旁的 `+`；展示资产选择，再展示「整理材料」技能 | 对话可以引用自己的文件和可复用技能。技能规定整理方法，不是再开一个聊天机器人。 |
| 18–28 秒 | 点击最近对话「OpenCode v1.19.3 · 推理配置阅读卡」 | 这里回放一次真实完成的任务：把官方发布摘要整理成阅读卡。 |
| 28–38 秒 | 展开「3 个步骤」，停留在 Agent 和工具记录 | 底层由 OpenCode 执行，依次研究资料、生成文稿和核对来源。处理过程可见，失败也直接显示。 |
| 38–50 秒 | 点击 Markdown 文件卡片，在右侧预览；进入编辑状态 | 结果不是只有一段聊天文字，而是一份可以继续修改的文稿。 |
| 50–60 秒 | 展示文稿已加入资产的状态，返回资产打开同一文稿 | 需要保留时，由用户加入资产，下次还能再次引用。积木重点做的是这条材料到成果的闭环。 |

## 录制原则

- 真实任务耗时可剪掉，标注「处理中已加速」，不替换执行结果。
- 已保存的阅读卡只展示保存状态，不演示不存在的再次保存按钮。
- 不宣称 MCP 全部可用，不演示未验收的自动登录、图片识别或视频转写。
- 不需要额外付费调用来录制上述回放。录制文件完成后再加入 README，当前脚本不是视频。
