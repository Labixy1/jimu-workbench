# 生成画板

## 方法
1. 确定用户要表达的流程或关系，只使用本次材料支持的信息。
2. 将流程压缩为3至8个步骤，每步8至24字；填入运行时page.diagram。
3. page.content简要说明流程、来源与边界，保留准确原文引用。
4. diagram表示顺序流程，不把并列关系强行连成因果；复杂网状图先拆成一条主流程。

## 输出
遵守运行时JSON结构。积木的本地布局工具将步骤生成Excalidraw图形，模型不写可执行绘图代码。
生成后可以预览、拖动图形和修改文字；用户点击加入资产才保存。

## 引用边界
引用已有画板只读取已保存文字，不识别截图、不推断箭头语义。不得编造来源、贡献或业务结果。
