# 积木网页采集 · 0.1.0

Chrome / Edge Manifest V3 扩展。用户自行打开页面并完成登录，点击扩展读取当前可见正文或选中文字，编辑预览，再在积木导入窗口确认保存。不是自主浏览器Agent，也不批量爬站。

安装：解压下载包 → Chrome打开`chrome://extensions`（Edge为`edge://extensions`）→ 开启开发者模式 → 加载已解压的扩展 → 选择含manifest.json的目录。只在用户点击时获取当前标签页的activeTab权限，无全站权限、后台采集、Cookie/密码接口、远程脚本。

积木必须本机运行8768端口。正文上限2万字，不自动截断；网址去除查询与锚点避免附带令牌。用URL片段带入本机预览，片段不发送服务器，积木读后立即清除并不自动保存或发送模型。片段短暂存在浏览器内存、历史/同步实现可能仍保留，不用于密码、账户信息或敏感资料；这种轻量传递不是加密保管机制。

登录只由用户在原站完成，不获取/转移登录会话、不绕过验证码/反爬。页面打开权限不代表有权转载；仅采集本人有权保存的内容。动态iframe、复杂招聘页可能只能手动选中/复制。网站导航、免责声明可能一并采集，必须预览清理。

本次验证提取函数与积木导入链路，未自动安装扩展，也未对真实招聘站扫码登录或完整Chrome扩展端到端验收。
