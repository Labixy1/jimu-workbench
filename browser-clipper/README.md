# 积木网页采集

Chrome / Edge Manifest V3 扩展，当前版本 0.2.0。用户打开文章并完成登录后，点击扩展读取当前正文或选中文字，再带到积木预览。不是自主浏览器 Agent，也不批量爬站。

## 安装与使用

1. 在积木的「扩展 → 连接器 → 浏览器采集」下载并解压插件。
2. 打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`，开启开发者模式，加载含 `manifest.json` 的目录。
3. 在原站正常打开文章，必要时自行登录。点击插件的「读取当前文章」，检查标题和正文；支持官网文章、公众号正文和小红书笔记。
4. 点击「带到积木预览」，选择资产目录，按需勾选阅览室与收藏分类，点击保存。

积木地址默认 `http://127.0.0.1:8768`，可在插件底部改为实际本机端口，只允许 localhost 或 127.0.0.1。正文最多 4 万字，不自动截断；超过时请选中所需片段重新读取。封面和日期只使用页面实际提供的信息，没有则留空。

## 权限与边界

- 仅申请 `activeTab` 和 `scripting`，只在用户点击时读取当前页；无全站权限、后台采集、Cookie/密码接口或远程脚本。
- 去除跟踪参数与登录令牌，保留文章身份参数。通过 URL 片段带到积木，积木读取后立即清除；正文不会自动保存或发送模型。
- URL 片段可能短暂出现在浏览器内存或历史中，不用于密码、账号资料等敏感内容，也不等同于加密传输保管。
- 不获取或转移登录会话，不绕过验证码和反爬限制。复杂动态页面可能需要选中文字；仅保存自己有权使用的材料，并检查采集正文。

提取与导入逻辑有自动化测试；实际安装插件、扫码登录属于用户操作，需要在目标浏览器单独验收。积木自带的 Browser Use 采集是另一条独立入口，不等同于此扩展的端到端验证。
